# eggress-protocol-socks

> Part of [eggress](https://github.com/eggstack/eggress) — a Rust-native, embeddable, multi-protocol proxy framework targeting compatibility with Python `pproxy==2.7.9`.

SOCKS4, SOCKS4a, and SOCKS5 server and client implementations for eggress.

## When to use this crate

Use `eggress-protocol-socks` directly when building custom SOCKS protocol handlers. Most users depend on this crate transitively through `eggress-server`.
